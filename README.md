Binance Historical Data DownloaderA lightweight Node.js utility to fetch and archive historical $1\text{m}$ candle data (OHLCV) from Binance Spot and Futures via REST API.FeaturesSpot & Futures Support: Fetch data from both Binance Spot and USDT-M Futures APIs.Auto-Syncing: Checks existing local files and fetches only missing recent candles to stay updated.$1\text{m}$ Granularity: Downloads complete 1-minute historical kline data.Rate-Limit Safe: Handles API pagination and rate limits smoothly.
